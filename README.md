# Alicia

Alicia’s family arcade, featuring **Star Sprout Adventure**—an original, side-scrolling platform game.

Explore long, procedurally varied levels, collect star seeds, bounce on roaming creatures, activate checkpoints, discover seed crates, and defeat the Cloudstone Guardian to reach the next stage.

## Controls

- Left / Right arrows: move
- Up arrow / Space: jump
- P: pause
- Esc: return to the arcade
- Music button: toggle the original synthesized soundtrack
